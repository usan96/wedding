# Data Model — 예식장 지도와 길찾기

## 예식장

| 필드 | 값 및 검증 |
| --- | --- |
| `venue_name`, `venue_address` | 기존 필수 문자열. 사용자가 확정한 예식장 이름과 도로명 주소를 유지한다. 홀과 층은 기존 화면 표시용 필드를 사용한다. |
| `directions` | 지도 설정 객체. 기존 파일을 미리볼 때 생략할 수 있다. 설정을 입력하는 경우 필수 하위 항목을 모두 검증한다. 게시에는 지도 설정이 필요하다. |
| `directions_url` | 기존 단일 웹 링크. `directions`가 없는 입력을 미리볼 때 기존 검증과 출력에 사용한다. 새 지도 설정으로 이행할 때 삭제하며, 함께 입력된 경우 새 지도 설정이 우선한다. |

## 지도 설정

| `directions` 하위 필드 | 값 및 검증 |
| --- | --- |
| `latitude`, `longitude` | 필수 WGS84 십진수 좌표. 유한한 JSON 숫자로 위도는 −90~90, 경도는 −180~180 범위여야 한다. 불리언은 숫자로 받지 않는다. 도로명 주소와 도착 위치의 일치는 지도에서 대조한다. |
| `map_image` | 필수 상대 경로. `assets/` 안의 유효한 PNG 또는 WebP 파일을 가리킨다. 실제 경로의 저장소 이탈, 파일 손실, 확장자와 이미지 형식의 불일치를 검증한다. 지도 핀과 주소의 일치는 화면에서 대조한다. |
| `naver_place_url` | 필수 HTTPS 링크. 네이버 지도의 해당 예식장 장소 상세 링크를 사용한다. 네이버 지도 상세 호스트 또는 네이버 공식 공유 호스트여야 하며 공유 링크가 최종적으로 같은 예식장 상세로 열리는지 확인한다. |
| `tmap_place_url` | 선택 HTTPS 링크. T맵에서 발급한 해당 예식장의 장소 공유 링크다. 등록한 경우 공식 공유 호스트를 검증한다. 주소 없이 설치 안내만 제공하는 링크는 웹 대체로 사용하지 않는다. |

T맵 공식 호출이 필요한 구성을 선택하면 생성 시 `TMAP_PUBLIC_APP_KEY`를 전달한다. 공식 호출 주소는 생성한 HTML에서 방문자에게 보이므로 공개 웹 사용과 범위 제한이 확인된 키만 이 변수에 넣는다. 키는 `invitation.json`에 저장하지 않는다. 앱 연결을 지원하는 장소 공유 링크만 사용하는 구성에서는 이 변수를 설정할 필요가 없다.

- 생성기는 기존 JSON 중복 필드 검사와 URL 형식 검증을 재사용한다. 링크는 서비스별 HTTPS 호스트를 정확히 비교하고 HTML 속성에 넣기 전에 이스케이프한다. 설정 오류는 해석 가능한 필드 경로와 함께 출력하고 미리보기나 게시 번들을 부분적으로 덮어쓰지 않는다.
- 대표 지도는 `venue_name`을 포함하는 대체 텍스트와 OpenStreetMap 출처 링크를 함께 표시한다. 미리보기는 원본 상대 경로를 사용하고 게시 번들은 `assets/venue-map.<확장자>`로 복사한다.
- 네이버 지도 앱 목적지와 카카오맵 웹 길찾기는 검증한 좌표에서 생성한다. 각 서비스에 맞는 좌표 순서를 적용하고 장소 이름은 URL 컴포넌트로 인코딩한다. T맵 공식 호출을 적용하는 경우 같은 좌표를 넘긴다. 키를 요구하는 호출은 공개 웹 사용이 허용된 프로젝트용 키를 확보한 경우에만 구성한다.
- T맵은 장소 공유 링크나 공식 목적지 호출 중 실기기에서 확인한 앱 연결 경로가 있어야 게시용 설정을 완료할 수 있다. 생성기는 유효한 구성의 존재를 검사할 수 있으며, 실제 앱 실행과 장소 일치는 수동으로 검증한다.
- 설정 상태는 기존 미리보기, 지도 설정 미리보기, 지도 설정과 예식 정보 확인 후 게시 순서로 전환한다. 예식장 변경 시 좌표, 지도 이미지, 서비스별 장소 링크를 함께 갱신하고 재검증한다.
