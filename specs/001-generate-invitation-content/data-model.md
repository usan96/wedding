# Data Model — 청첩장 정보 자동 반영

## 청첩장 입력 정보

입력 파일은 UTF-8 JSON 객체 하나다. 아래 키를 사용하며 중복되거나 정의되지 않은 키는 오류로 안내한다. 문자열 필수 항목은 비어 있거나 공백만 있으면 오류다.

| 필드 | 형식 | 검증 및 표시 |
| --- | --- | --- |
| `status` | `draft` 또는 `confirmed` | 미리보기에서 예시와 확정 입력을 구분한다. 게시용 번들은 `confirmed`가 필요하다. |
| `groom_name`, `bride_name` | 문자열 | 필수. 이름의 글자와 순서를 유지하고 제목, 표지, 인사말에 같은 값을 표시한다. |
| `date` | `YYYY-MM-DD` 문자열 | 필수. 실제 달력에 있는 예식장 현지 날짜. 요일, 달력 월과 예식일 강조의 기준이다. |
| `time` | `HH:MM` 문자열 | 필수. 24시간제 예식장 현지 시작 시각. 화면에서는 한국어 오전·오후 표기를 사용한다. |
| `venue_name`, `venue_address` | 문자열 | 필수. 확정한 예식장 이름과 주소다. |
| `venue_hall`, `venue_floor` | 문자열 | 선택. 키를 생략하거나 값을 비워 두면 해당 항목을 숨긴다. |
| `directions_url` | 문자열 | 필수. 호스트가 있는 절대 HTTP(S) URL. 공백·제어 문자·역슬래시·사용자 인증 정보를 허용하지 않고, 포트가 있으면 범위를 검증한다. 실제 목적지는 작성자가 확인한다. |
| `cover_photo` | 저장소 상대 경로 문자열 | 필수. `assets/` 내부에 실제로 존재하는 JPG, JPEG, PNG, WebP 파일을 가리킨다. 제공된 `sample.png`는 초안에서 사용할 수 있다. 경로를 해석한 결과가 허용 범위를 벗어나면 오류다. |
| `cover_photo_alt` | 문자열 | 선택. 비어 있거나 생략하면 기본 표지 사진 설명을 사용한다. |

제공된 예시 문자열, `example.com` 길찾기 주소, 기본 예시 사진 `sample.png`와 동일한 파일은 확정 입력에 사용할 수 없다. `confirmed`는 작성자가 이름, 예식 안내, 지도 목적지와 사진을 대조했다는 표시다.

## 생성된 청첩장

- **미리보기** — 검증된 입력과 동일한 템플릿을 사용해 저장소 루트의 `index.html`을 만든다. 초안이면 화면 표시와 초안 마커, `noindex`를 포함한다. 생성 실패 시 이전 성공 결과를 유지한다.
- **게시용 번들** — 확정 입력으로 다시 생성한 `index.html`과 페이지가 참조하는 CSS, JS, 사진 한 장이다. 기존 미리보기의 유무와 상관없이 현재 입력을 검증한다. 복사하는 사진은 일반 파일로 스테이징한다.
- **파생 표시값** — 예식장 현지 값으로부터 짧은 날짜, 긴 날짜와 요일, 오전·오후 시각, 달력 제목과 일요일부터 시작하는 주 단위 표를 만든다. `00:00`은 오전 12시, `12:00`은 오후 12시다. 해당 월의 예식일 한 칸만 강조한다.

## 상태 전이

1. 작성자는 제공된 `draft`로 예시 미리보기를 만들거나, 초안 상태에서 값을 채워 검토한다.
2. 확정 자료와 화면을 대조한 뒤 `confirmed`로 바꾼다. 값이 바뀌면 다시 대조한 후 게시한다.
3. 생성 명령은 매번 현재 입력을 읽고 검증한다. 초안 상태의 게시 시도 또는 유효하지 않은 입력은 실패하며, 정정한 뒤 다시 실행할 수 있다.
