# Phase 0 Research: 예식 일정 위 사진 갤러리

## 사진 선택과 표시 순서

- **결정** — 공개할 사진을 모아 두는 `assets/`와 하위 폴더의 이미지 파일을 수집한다. 파일명은 영문 대소문자를 구분하지 않고 비교하며, 이름이 같으면 상대 경로로 순서를 결정한다.
- **근거** — 작성자는 사진을 복사하거나 이름을 바꾸는 작업만으로 갤러리 구성과 순서를 관리할 수 있다.
- **검토한 대안** — 명시적인 사진 목록은 사진을 추가하거나 순서를 변경할 때 파일 경로를 별도로 편집해야 한다.

## 생성 검증과 게시

- **결정** — 기존 사진 검증을 재사용하고 항목별 오류 위치를 전달한다. 기존 예시 사진 `sample.png`와 내용이 같은 파일을 확정 입력에서 거부한다. 미리보기에서는 원본을 상대 경로로 참조하고, 게시본에서는 목록 순번으로 이름을 정한 파일을 임시 번들에 복사한 뒤 번들을 공개 경로에 옮긴다.
- **근거** — 생성기가 이미 경로 범위, 파일 확장자, 파일 내용, 예시 여부를 검증한다. 게시 시 검증한 사진만 복사하고, 순번 기반 경로를 사용해 원본 파일명이 같아도 충돌하지 않는다.
- **검토한 대안** — `assets/` 전체 복사는 사진 외의 자료도 게시한다. 목적지에 바로 쓰면 복사 실패 시 조립 중인 번들이 남는다.

## 레이아웃과 이미지 로딩

- **결정** — 본문에는 첫 사진을 크게 배치한 최대 5장의 모자이크를 표시한다. 썸네일을 선택하면 대화상자에서 사진의 원래 비율과 설명을 유지하고 전체 목록을 탐색할 수 있다. 썸네일에는 브라우저 기본 지연 로딩을 사용한다.
- **근거** — 첫 사진과 여러 장의 썸네일이 한눈에 보인다. 본문 갤러리 높이가 사진 수에 따라 늘어나지 않고, 개별 이미지의 로드 실패는 일정이나 다른 사진의 탐색을 가로막지 않는다.
- **검토한 대안** — 가로 스크롤은 한 번에 볼 수 있는 사진 수가 줄어든다. 전체 사진을 세로로 배치하면 예식 일정에 도달하기까지 더 많이 스크롤해야 한다.
