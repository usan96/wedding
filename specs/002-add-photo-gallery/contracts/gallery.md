# Contract: 사진 갤러리 입력과 표시

## 작성자 입력

공개할 JPG, JPEG, PNG, WebP 사진을 `assets/`에 넣는다. 생성기는 하위 폴더를 포함해 사진을 자동으로 찾고 파일명 사전순으로 표시한다. 지원 이미지 파일이 없으면 갤러리 제목과 영역을 생략한다. 기존 `gallery_photos` 항목의 설명은 파일 경로가 일치할 때 사용한다.

입력 검증과 정렬 규칙은 [데이터 모델](../data-model.md)을 따른다.

## 생성 CLI

| 명령 | 성공 시 결과 |
| --- | --- |
| `uv run python scripts/generate_invitation.py` | 기존 방식으로 저장소 루트에 `index.html`을 생성한다. 갤러리 이미지 주소는 해당 원본을 가리키는 상대 경로다. |
| `uv run python scripts/generate_invitation.py --publish-dir <새-출력-경로>` | `confirmed` 입력으로 게시 번들을 만든다. 갤러리 이미지는 첫 항목부터 `./assets/gallery/001.<확장자>` 형식의 상대 주소로 제공된다. 확장자는 소문자를 사용한다. |

두 명령 모두 입력 오류에 종료 코드 1과 문제 위치·원인을 반환한다. 예를 들어 이미지의 형식이 잘못되면 해당 `assets/` 경로가 오류에 포함된다. 실패 시 이전 미리보기와 기존 게시 경로를 보존한다. 번들에는 표지 사진과 검증한 갤러리 사진, 기존 정적 사이트 파일을 담는다.

## 하객 화면

- 사진이 한 장 이상이면 ‘사진’ 제목을 붙인 영역이 인사말 바로 뒤, ‘예식 일정’ 바로 앞에 표시된다.
- 사진은 파일명 사전순으로 보이며 화면 읽기 프로그램이 각 사진의 대체 텍스트를 읽을 수 있다.
- 본문에는 대표 썸네일을 최대 5장 표시한다. 사진이 더 있으면 남은 장수를 표시한다. 상세 보기에서는 사진을 원래 비율로 표시하며 이전·다음 버튼이나 좌우 방향키로 전체 목록을 탐색할 수 있다.
- 사진 하나를 불러오지 못해도 다른 사진과 예식 일정, 길찾기를 이용할 수 있다.
- 동일한 결과물을 사이트 루트나 `/wedding/` 경로에 배치해도 상대 주소로 사진을 불러올 수 있다.
