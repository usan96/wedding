# Contract: 사진 갤러리 입력과 표시

## 작성자 입력

사진을 `assets/`에 준비한 뒤 `invitation.json`의 최상위 객체에 다음 형식으로 추가한다. 파일명과 설명은 작성자가 선택한 사진에 맞게 바꾼다.

```json
{
  "gallery_photos": [
    {"path": "assets/정원 사진.jpg", "alt": "정원에서 손을 잡은 신랑과 신부"},
    {"path": "assets/입구 사진.webp", "alt": "예식장 입구에 나란히 선 신랑과 신부"}
  ]
}
```

배열 순서가 표시 순서다. `gallery_photos`를 생략하거나 `[]`를 사용하면 갤러리 제목과 영역이 함께 생략된다. 입력 검증 규칙은 [데이터 모델](../data-model.md)을 따른다.

## 생성 CLI

| 명령 | 성공 시 결과 |
| --- | --- |
| `uv run python scripts/generate_invitation.py` | 기존 방식으로 저장소 루트에 `index.html`을 생성한다. 갤러리 이미지 주소는 해당 원본을 가리키는 상대 경로다. |
| `uv run python scripts/generate_invitation.py --publish-dir <새-출력-경로>` | `confirmed` 입력으로 게시 번들을 만든다. 갤러리 이미지는 첫 항목부터 `./assets/gallery/001.<확장자>` 형식의 상대 주소로 제공된다. 확장자는 소문자를 사용한다. |

두 명령 모두 입력 오류에 종료 코드 1과 문제 위치·원인을 반환한다. 예를 들어 두 번째 사진을 찾을 수 없으면 `gallery_photos[1].path`가 오류에 포함된다. 실패 시 이전 미리보기와 기존 게시 경로를 보존한다. 번들에는 표지 사진과 선택한 갤러리 사진, 기존 정적 사이트 파일을 담는다.

## 하객 화면

- 사진이 한 장 이상이면 ‘사진’ 제목을 붙인 영역이 인사말 바로 뒤, ‘예식 일정’ 바로 앞에 표시된다.
- 사진은 입력 순서대로 보이며 화면 읽기 프로그램이 각 사진의 대체 텍스트를 읽을 수 있다.
- 사진은 영역 폭에 맞고 원래 비율을 유지한다. 사진 하나를 불러오지 못해도 다른 사진과 예식 일정, 길찾기를 이용할 수 있다.
- 동일한 결과물을 사이트 루트나 `/wedding/` 경로에 배치해도 상대 주소로 사진을 불러올 수 있다.
