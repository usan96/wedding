# Data Model: 예식 일정 위 사진 갤러리

## 청첩장 입력

`Invitation`의 갤러리 사진 목록은 `assets/`와 하위 폴더의 이미지 파일에서 생성한다. 파일명은 영문 대소문자를 구분하지 않고 비교하며 이름이 같으면 상대 경로로 순서를 결정한다. 표지 사진은 기존 필드를 사용하고 `assets/` 안에 있으면 갤러리 목록에도 포함한다.

## 갤러리 사진

| 입력 필드 | 필수 여부 | 검증 및 의미 |
| --- | --- | --- |
| `path` | 자동 | 프로젝트 `assets/` 안에서 발견한 유효한 JPG, JPEG, PNG, WebP 파일의 경로. |
| `alt` | 선택 | 기존 `gallery_photos` 항목에 있는 동일 경로의 설명. 설명이 없으면 화면에서 사용하는 대체 텍스트는 ‘웨딩 사진 1’처럼 순서대로 붙인다. |

지원 확장자를 가진 파일을 읽을 수 없거나 형식이 맞지 않으면 오류에 경로와 원인을 표시한다. 확정 입력에서는 기존 표지 검사와 같은 방식으로 기본 예시 파일과 내용이 같은 사진도 거부한다. 기존 설명 목록의 중복 키 오류에는 항목 위치를 표시하며 배열 위치는 0부터 센다.

## 생성 결과와 상태

- **입력 검증 성공** — 검증된 경로와 설명을 파일명 사전순으로 유지한다. 초안에 예시 사진이 포함되면 초안 표시에서 그 사실을 알린다.
- **미리보기** — 원본 파일을 가리키는 프로젝트 상대 경로를 사용한다. 렌더링에 성공하면 기존 미리보기를 교체한다.
- **게시 번들** — 확정된 목록의 각 사진을 `assets/gallery/001.jpg`처럼 순서에 따른 경로로 매핑한다. HTML과 각 이미지가 준비되면 최종 위치로 옮긴다.
- **실패** — 이전 미리보기를 보존하고 배포할 새 번들을 만들지 않는다.

필드 예제와 생성 명령은 [갤러리 계약](contracts/gallery.md)에 있다.
