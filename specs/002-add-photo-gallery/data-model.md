# Data Model: 예식 일정 위 사진 갤러리

## 청첩장 입력

기존 `Invitation`에 순서가 있는 갤러리 사진 목록을 추가한다. JSON에서 `gallery_photos`가 생략되거나 빈 배열이면 생성기에서 빈 목록으로 읽는다. 목록의 앞 항목부터 화면에 표시하며 표지 사진은 별도의 기존 필드를 사용한다.

## 갤러리 사진

| 입력 필드 | 필수 여부 | 검증 및 의미 |
| --- | --- | --- |
| `path` | 필수 | 공백만으로 이루어지지 않은 상대 경로. 프로젝트 `assets/` 안의 유효한 JPG, JPEG, PNG, WebP 파일을 가리킨다. 기본 예시 `sample.png`는 초안에서 지정할 수 있다. |
| `alt` | 선택 | UTF-8로 표현할 수 있는 문자열. 생략하거나 빈 값이면 화면에서 사용하는 대체 텍스트는 ‘웨딩 사진 1’처럼 순서대로 붙인다. |

각 항목은 객체다. 잘못된 자료형, 미지원 필드, 누락되거나 읽을 수 없는 사진, 형식이 맞지 않는 파일은 실패 처리한다. 오류에 항목 위치와 원인을 표시하며 배열 위치는 0부터 센다. 확정 입력의 경우 기존 표지 검사와 같은 방식으로 기본 예시 파일과 내용이 같은 사진도 거부한다.

## 생성 결과와 상태

- **입력 검증 성공** — 검증된 경로와 설명을 목록 순서대로 유지한다. 초안에 예시 사진이 포함되면 초안 표시에서 그 사실을 알린다.
- **미리보기** — 원본 파일을 가리키는 프로젝트 상대 경로를 사용한다. 렌더링에 성공하면 기존 미리보기를 교체한다.
- **게시 번들** — 확정된 목록의 각 사진을 `assets/gallery/001.jpg`처럼 순서에 따른 경로로 매핑한다. HTML과 각 이미지가 준비되면 최종 위치로 옮긴다.
- **실패** — 이전 미리보기를 보존하고 배포할 새 번들을 만들지 않는다.

필드 예제와 생성 명령은 [갤러리 계약](contracts/gallery.md)에 있다.
